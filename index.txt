    <h1>瑜伽哲學與理論 考試總整理</h1>

    <!-- 一、印度哲學派別與數論哲學 -->
    <h2>一、印度哲學派別與數論哲學（Sankhya）架構</h2>
    <h3>1. 六大正統哲學派別（Orthodox，依據《吠陀經》）</h3>
    <ul>
        <li><span class="highlight">Sankhya（數論）</span>：創始者為聖哲卡皮拉（Kapil）。與 25 個數字相關，故稱數論。</li>
        <li><span class="highlight">Yoga（瑜伽）</span>：創始者為 Patanjali（帕坦伽利，修練在實踐端/瑜伽經）。</li>
        <li><span class="highlight">Nyaya（正理論）</span>：創始者為 Gautama。</li>
        <li><span class="highlight">Vaisheshik（勝論）</span>：創始者為 Maharshi Kanada。</li>
        <li><span class="highlight">Mimansa（彌曼差）</span></li>
        <li><span class="highlight">Vedanta（吠壇多）</span>：創始者為 Shankara Charya。</li>
    </ul>
    <p><em>(註：非依據吠陀經的哲學派別稱為 Hetrodox，如：佛教、耆那教、查瓦克 Charmwaka)</em></p>

    <h3>2. 數論哲學 25 演化體系（Purusha 與 Prakriti）</h3>
    <ul>
        <li><span class="highlight">Purusha（靈 / 神我）</span>：永恆不變、純粹意識。</li>
        <li><span class="highlight">Prakriti（原質）</span>：物質世界的根本，誤認與 Purusha 結合後展開演化：
            <ul>
                <li><span class="highlight">Mahat（智力 / Intellect）</span>
                    <ul>
                        <li><span class="highlight">Ahankara（自我 / Ego / 我執）</span>：向下分化為三性</li>
                    </ul>
                </li>
            </ul>
        </li>
    </ul>

    <h3>3. 三性（Gunas）、器官與元素</h3>
    <ul>
        <li><span class="highlight">愉悅性（Sattva）</span>：
            <ul>
                <li><strong>Manas（心智 / Mind）</strong></li>
                <li><strong>五感覺器官</strong>：眼、耳、鼻、舌、皮</li>
                <li><strong>五行動器官</strong>：手、腳、嘴、排泄、生殖</li>
            </ul>
        </li>
        <li><span class="highlight">變性（Rajas）</span>：不產生實體，提供能量與驅動力。</li>
        <li><span class="highlight">惰性（Tamas）</span>：
            <ul>
                <li><strong>五感受 / 感覺</strong>：視覺、聲、氣味、味覺、觸覺</li>
                <li><strong>五大元素</strong>：空、風、火、水、土</li>
            </ul>
        </li>
    </ul>

    <h3>4. 人生的五大問題（解脫對象）</h3>
    <p>無知、有我、執著、死懼、排斥。</p>

    <!-- 四、調息法 -->
    <h2>四、調息法（Pranayama）五大種類、好處與禁忌</h2>
    <ul>
        <li>
            <span class="highlight">1. Nadi Shodhan Pranayama（脈叢淨化呼吸法 / 陰陽呼吸法）</span>
            <ul>
                <li><strong>好處</strong>：平衡左右腦與陰陽能量（Ida 與 Pingala 脈），平撫神經系統、減輕壓力與焦慮，提升專注力[cite: 1]。</li>
                <li><span class="warning">禁忌</span>：無特別嚴格禁忌；嚴重鼻塞時不宜強行鼻吸鼻吐。</li>
            </ul>
        </li>
        <li>
            <span class="highlight">2. Seetkari Pranayama（嘶聲呼吸法）</span>
            <ul>
                <li><strong>好處</strong>：冷卻身體與血液系統、降低體溫與血壓，舒緩憤怒與焦慮，並有助於減緩牙齦問題。</li>
                <li><span class="warning">禁忌</span>：低血壓患者、哮喘或呼吸道疾病者、嚴重便秘者、氣管過敏者不宜練習。</li>
            </ul>
        </li>
        <li>
            <span class="highlight">3. Bhramari Pranayama（蜜蜂呼吸法）</span>
            <ul>
                <li><strong>好處</strong>：透過蜂鳴聲震動平撫腦神經，緩解緊張、頭痛與失眠，促進睡眠品質並降血壓。</li>
                <li><span class="warning">禁忌</span>：嚴重耳部感染者、肺部嚴重感染或發炎者不宜練習。</li>
            </ul>
        </li>
        <li>
            <span class="highlight">4. Ujjai Pranayama（勝利呼吸法）</span>
            <ul>
                <li><strong>好處</strong>：增加體內熱能、清理呼吸道，增強肺活量，幫助冥想時保持覺知與專注。</li>
                <li><span class="warning">禁忌</span>：嚴重高血壓、心臟病或甲狀腺亢進者應避免過度用力或屏息。</li>
            </ul>
        </li>
        <li>
            <span class="highlight">5. Bhastrika Pranayama（風箱呼吸法）</span>
            <ul>
                <li><strong>好處</strong>：快速增加血液含氧量、促進消化火（Agni）、清除體內毒素與黏液，提供身體能量。</li>
                <li><span class="warning">禁忌</span>：高血壓、心臟病、癲癇、青光眼、胃潰瘍、懷孕期間及近期做過腹部手術者嚴禁練習。</li>
            </ul>
        </li>
    </ul>

    </ul>

    <!-- 七、梵咒 -->
    <h2>七、梵咒（Mantra）基礎概念</h2>
    <ul>
        <li><strong>定義與含意</strong>：聲音振動，字根取自 <em>mananaat</em>（心靈的束縛）與 <em>trayate</em>（釋放）[cite: 1]。</li>
        <li><strong>功能</strong>：將心智從不潔（mala）與不滿足（vikshepa）的束縛中解放出來，驅散雜念[cite: 1]。</li>
        <li><strong>類別</strong>：Universal（普遍性）與 Individual（個人性）[cite: 1]。</li>
    </ul>

    <!-- 九、脈叢 / 梵結定義與分類 -->
    <h2>九、脈叢 / 梵結（Granthi）定義與分類</h2>
    <p><strong>定義</strong>：Granthi 原意為「結」或「阻礙」，指在中脈（Sushumna Nadi）上影響生命能量（Prana）上升的三個主要精神與能量結節[cite: 1]。能量穿透這些結節才能順利升至頂輪達到覺悟。</p>
    <ul>
        <li><span class="highlight">Brahma Granthi（梵天結）</span>：由<strong>海底輪與生殖輪</strong>組成。代表對物質世界、肉體生存與本能慾望的執著。</li>
        <li><span class="highlight">Vishnu Granthi（毗濕奴結）</span>：由<strong>臍輪與心輪</strong>組成。代表對情感、關係、權力與名利的執著。</li>
        <li><span class="highlight">Rudra Granthi / Shiva Granthi（濕婆結）</span>：由<strong>喉輪與眉心輪</strong>組成。代表對個人智力、靈性能力及自我超能力的執著。</li>
    </ul>

    <h2>十、精微體（Kosha）、生命氣（Prana Vayus）與經脈（Nadis）</h2>
    <h3>1. 精微體五層（Kosha）[cite: 1]</h3>
    <p>Annamaya Kosha（食物鞘） | Pranamaya Kosha（能量鞘） | Manomaya Kosha（心智鞘） | Vijnanamaya Kosha（智慧鞘） | Anandamaya Kosha（喜悅鞘）[cite: 1]</p>

    <h3>2. 五大生命氣（Prana Vayus）[cite: 1]</h3>
    <p>Prana Vayu（胸部/吸氣） | Apana Vayu（下腹/排泄） | Samana Vayu（肚臍/消化） | Udana Vayu（喉頭/向上） | Vyana Vayu（全身/循環）[cite: 1]</p>

    <h3>3. 三大主脈（Nadis）[cite: 1]</h3>
    <p>Sushumna Nadi（中脈） | Ida Nadi（左脈/陰/月亮） | Pingala Nadi（右脈/陽/太陽）[cite: 1]</p>

    <!-- 十二、冥想 -->
    <h2>十二、冥想（Meditation / Dhyana）概念與步驟</h2>
    <h3>1. 冥想的定義與分類</h3>
    <ul>
        <li><strong>凝神（Dharana）與冥想（Dhyana）的差異</strong>：凝神時心智仍會不斷干擾，修練者需持續將注意力拉回目標；冥想則是克服外在干擾，心智完全且持續全神貫注於目標。</li>
        <li><strong>冥想兩大類型</strong>：
            <ul>
                <li><span class="highlight">主動冥想（Active Meditation）</span>：修練者自發每天練習冥想一次（如日常工作時的主動專注）。</li>
                <li><span class="highlight">被動冥想（Passive Meditation）</span>：坐在特定姿勢便開始冥想練習（如清晨或睡前洗澡後進行）。</li>
            </ul>
        </li>
    </ul>

    <h3>2. 冥想的 5 大步驟</h3>
    <ol>
        <li><strong>Preparation</strong>（準備）</li>
        <li><strong>Body Stillness</strong>（身體靜止）</li>
        <li><strong>Sense Withdrawal</strong>（感官撤離）</li>
        <li><strong>Dharana</strong>（凝神）</li>
        <li><strong>Meditation</strong>（冥想）</li>
    </ol>
